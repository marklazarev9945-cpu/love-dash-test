# LOVE DASH v0.3A.2 — Park Motion Fix

## Запуск
Открой `runner/index.html` двойным щелчком (без сервера). Для GitHub Pages загрузи папку `runner/` в репозиторий и открой опубликованный `runner/index.html`. Никакой сборки, npm или внешних зависимостей нет.

## Управление
Клавиатура: ← и →; пробел или Esc — пауза. На телефоне — свайп влево/вправо по игровой области или экранные стрелки. Кнопки «Пауза» и «Начать заново» доступны сверху. При потере всех трёх жизней нажми «Продолжить»: сердца сохранятся. После 100 сердец собери кольцо; пропущенное кольцо появится снова.

## Изменения относительно v0.3A.1
- Исправлено направление и отсечение парковых декораций: глубина `z = state.travel - item.distance` увеличивается с общим продвижением мира; удаление происходит только после ухода **верхнего края** изображения ниже Canvas.
- Та же `projectDepth(z)` используется для сердца, барьера и парковой декорации. Скорость у всех общая: `speed()` и `state.travel += dt * speed()`.
- Декорации заполняют аллею плотнее, но не рисуются на трёх игровых полосах (обрезка по боковым областям).
- На всём протяжении забега (0–100 и кольцо) остаётся Бутовский парк; код остальных локаций сохранён, автоматическое переключение отключено.
- Движущиеся поперечные линии отсутствуют. Персонаж, ввод, спавн игровых предметов, столкновения и условия победы не изменены.

## Проверка
В `game.js` есть `DEBUG_MOTION = false` — только для локальной диагностики можно поставить `true` и посмотреть скорость, расстояние, глубину сердца и парковой декорации. Верни `false` перед публикацией. Параметр `LOCAL_TEST_99_HEARTS = false` можно локально переключить для быстрой проверки кольца; перед публикацией вернуть `false`.

## Ограничения
Парк нарисован средствами Canvas и не является финальным оформлением. Реальное визуальное прохождение декораций, производительность и комфорт на iPhone требуют пользовательской проверки. Остальные три локации оставлены в коде для будущих решений, но не отображаются в этой версии.
